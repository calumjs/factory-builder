# Learn

<!-- phase-compact:v1 -->

1. Read learning-log.md, actual run evidence and config.assumptions. Follow the [Learn guide](../../../phase-learn-guide.md) before recording outcomes, integrating shared evidence or proposing upstream work.
2. Separate facts from hypotheses; retain failures and unresolved assumptions. Reconcile intended versus executed scope, exact subjects, unique test counts, skipped/not-run outcomes and retries using the guide. Coordinate evidence integration serially. Refresh an overview only when requested; counts are recorded claims. Propose the smallest useful improvement with an owner and evaluation measure.
Assess current intake and video choices using the guide.
3. Exit with a reviewed improvement proposal and remaining blockers. Contract, policy, provider or production changes require their own scope; upstream sharing follows the guide's provenance and authorization procedure.
4. Return: status, input/output revision, artifacts, checks actually run, blockers and risks, next owner/action. A template, plan or config proves nothing ran.
